
# 🍳 Recipe & Meal Planner App

A clean, interactive Recipe & Meal Planner mobile application built with **Flutter** and **Dart**. Designed to organize meals by categories and offer expandable recipe cards for ingredients and cooking instructions.

---

## 🌟 Key Features

* **Meal Category Filtering:** Filter recipes seamlessly by *Breakfast, Lunch, Dinner,* or view *All* meals.
* **Expandable Recipe Cards:** Tap on any recipe tile using `ExpansionTile` to view itemized ingredients and cooking steps.
* **Interactive UI:** Smooth transitions, responsive layout, and clean visual indicators.

---

## 🛠️ Built With

* **Flutter** - Cross-Platform Toolkit
* **Dart** - Object-Oriented Programming Language
